# ChatRelay

Плагин для сервера Minecraft на Purpur или Paper. Копит чат игроков в памяти и отдаёт его по команде `/chatpull`, когда её вызывает телеграм-бот. Нужен для того, чтобы бот показывал сообщения с сервера прямо в телеграме.

## Зачем он

Бот отправляет сообщения из телеграма на сервер обычным `tellraw` по RCON. Для этого плагин не нужен. А вот чтобы забрать сообщения игроков обратно в телеграм, серверу нужен кто-то, кто их накопит и выдаст по запросу. Этим и занимается ChatRelay.

Без плагина бот работает. Просто чат сервера в телеграм приходить не будет.

## Как работает

- Каждое сообщение в чате ловится через `AsyncChatEvent` и попадает в буфер: ник и текст, все цветовые коды заранее вырезаны.
- Бот раз в 10 секунд вызывает `/chatpull` по RCON. Команда забирает всё из буфера и возвращает одним блоком, каждая строка вида `[Ник]: текст`.
- Сообщение живёт 15 секунд. Не забрали - удаляется. Чистка идёт раз в 5 секунд, так что буфер не разрастётся, даже если бот отвалился.
- Никаких открытых портов и HTTP. Всё через тот же RCON-канал, который уже настроен для бота.

## Требования

- Purpur или Paper 1.21+. Написан и работает на Purpur, это форк Paper.
- Java 21.
- Включённый RCON на сервере.

## Установка

1. Скачай `ChatRelay-1.0.0.jar` из раздела Releases.
2. Положи его в папку `plugins/` сервера.
3. Перезапусти сервер.
4. Убедись, что RCON включён в `server.properties`: `enable-rcon=true`, заданы `rcon.port` и `rcon.password`.

Право `chatrelay.use` по умолчанию есть у оператора. RCON-консоль работает с правами оператора, поэтому команда проходит без дополнительной настройки.

## Сборка из исходников

Если хочешь собрать сам:

```bash
mvn package
```

Готовый jar появится в `target/ChatRelay-1.0.0.jar`.

## Команда

`/chatpull` забирает накопленные сообщения и возвращает их. Она нужна боту и вызывается по RCON. Руками её звать смысла нет.

## Бот

Работает в паре с ботом The Abyss. Репозиторий: https://github.com/Hakhuh/the-abyss-bot
